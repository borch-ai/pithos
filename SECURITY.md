# Security Policy

## Reporting a Vulnerability

We take the security of **Pithos** seriously. If you find any security vulnerabilities, please do **not** open a public issue. Instead, report them responsibly.

Please report security issues by emailing the development team at:
**security@sinope.press**

### What to Include
When reporting a vulnerability, please provide the following details to help us investigate and patch it quickly:
- A description of the issue.
- Steps to reproduce (including a proof-of-concept if possible).
- The potential impact.

### Our Commitment
Upon receiving a vulnerability report, we commit to:
- Acknowledging the receipt of the report within 48 hours.
- Working on a resolution/patch diligently.
- Providing updates as we resolve the issue.
- Publicly disclosing the vulnerability and acknowledging your contribution once a patch is successfully deployed.
